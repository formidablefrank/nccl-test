# nccl-test

Small MPI + NCCL test application for Leonardo. The program initializes MPI, chooses one GPU per rank, creates an NCCL communicator, and runs a single `ncclAllReduce` to verify multi-node, multi-GPU communication.

## How it works

The execution flow is:

1. MPI starts the job and discovers `rank` and `world size`.
2. Each rank computes a host hash from the hostname plus the machine boot ID to infer its local rank on the node.
3. The local rank is used to select a GPU with `localRank % deviceCount`.
4. Rank 0 generates an NCCL unique ID and broadcasts it to all ranks.
5. Every rank allocates CUDA buffers, initializes NCCL, and launches one `ncclAllReduce` on a CUDA stream.
6. The stream is synchronized, resources are released, and MPI finalizes.

The current source uses a default message size of `32 * 1024 * 1024` floats, but you can override it from the command line.

## Tech stack

- C
- MPI
- CUDA Runtime API
- NVIDIA NCCL
- Bash for launch scripts
- Slurm for batch scheduling on Leonardo

## Folder structure

- `allreduce.c` - main MPI/NCCL/CUDA all-reduce program
- `allreduce.x` - compiled executable
- `nccl.sh` - module setup and environment variables for NCCL/CUDA/MPI
- `binder.sh` - rank-to-GPU and rank-to-network-device binding helper
- `batch.sh` - Slurm batch script for Leonardo
- `topo_leo.xml` - NCCL topology dump generated by the job
- `logs/` - Slurm stdout/stderr and NCCL debug logs

## Build

On Leonardo, first load the same compiler and communication stack used by the job script:

```bash
module purge
source nccl.sh
```

Then compile the program:

```bash
nvcc allreduce.c -o allreduce.x -lmpi -lnccl
```

If your environment requires different module paths or a different NCCL install, keep the same library/include setup from `nccl.sh` and adjust it for your account or software stack.

## Run on Leonardo

The repository is already set up for a 4-node, 16-rank run with 4 GPUs per node. Submit the batch script with Slurm:

```bash
sbatch batch.sh
```

`batch.sh` does the following:

- requests 4 nodes
- launches 4 MPI tasks per node
- requests 4 GPUs per node
- sets NCCL debug output and topology dump paths
- starts the job with:

```bash
mpirun -np 16 ./binder.sh ./allreduce.x 50000000
```

The final argument is the message size in floats. If you omit it, `allreduce.c` uses its built-in default.

## Scripts

### `nccl.sh`

Loads the Leonardo module stack and exports the include and library paths for NCCL.

### `binder.sh`

Maps each MPI rank to a specific network device and CUDA device:

- rank 0 -> `mlx5_0:1`, GPU 0
- rank 1 -> `mlx5_1:1`, GPU 1
- rank 2 -> `mlx5_2:1`, GPU 2
- rank 3 -> `mlx5_3:1`, GPU 3

It then launches the wrapped command.

### `batch.sh`

Contains the Slurm directives and the actual launch command used on Leonardo. It also enables NCCL debug logging and writes a topology dump to `topo_leo.xml`.

## Output

Successful runs print one line per MPI rank:

```text
[MPI Rank <rank>] Success
```

Slurm stdout/stderr and NCCL logs are written under `logs/`.

## Notes

- `batch.sh` contains Leonardo-specific account, partition, and QoS values. Update them if you run under a different project.
- If you want to benchmark different message sizes, pass a different final argument to `allreduce.x` in `batch.sh`.
- `topo_leo.xml` is regenerated by the job when `NCCL_TOPO_DUMP_FILE` is set.
